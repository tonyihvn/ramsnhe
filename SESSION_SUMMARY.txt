# Voice Capture Guidelines Save Issue - Session Summary

## Problem Statement
User could not save voice capture guidelines in Form Builder. When clicking "Voice Guidelines" button, the UI appeared to work but data was not persisted to the database.

## Root Cause Analysis
API payload mismatch between frontend and backend:

Frontend (hooks/useVoiceApi.ts:177):
  POST /api/voice-capture/form/{formId}/guidelines
  Payload: { guidelines: { is_enabled, ai_guide_text, ... } }
  ❌ Wrapped in extra object

Backend (server/voice-capture-routes.js:256):
  Expected: { is_enabled, ai_guide_text, ... }
  ✅ Direct extraction from req.body
  const { is_enabled, ai_guide_text, ... } = req.body;

Result: Backend couldn't find the expected fields, silently failed.

## Solution Implemented
Fixed hooks/useVoiceApi.ts line 187:

BEFORE:
  await axios.post(`/api/voice-capture/form/${formId}/guidelines`, {
    guidelines  // Wrapper object - WRONG
  });

AFTER:
  await axios.post(`/api/voice-capture/form/${formId}/guidelines`, guidelines);
  // Direct pass - CORRECT

## Voice Capture System Overview
After this fix, the complete workflow is:

1. CONFIGURE GUIDELINES (Form Builder)
   - Form Builder → Voice Guidelines button
   - User enters: is_enabled, interviewer_guide, ai_guide, custom_prompt
   - Click Save
   - ✅ Guidelines saved to database (NOW WORKS)

2. RECORD INTERVIEW (Form Fill)
   - Form Fill page → Start Voice Capture button
   - Display interviewer guide
   - Record audio
   - Transcribe via speech-to-text service

3. EXTRACT DATA (Backend)
   - Fetch transcribed text
   - Fetch form guidelines (NOW AVAILABLE)
   - Fetch form structure (fields, types, options)
   - Fetch AI context (if configured)
   - Build LLM prompt with all context
   - Call LLM to extract data

4. AUTO-POPULATE (Frontend)
   - Display extracted data
   - Auto-fill form fields
   - User reviews and edits
   - Save activity
