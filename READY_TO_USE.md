## 🆘 Troubleshooting

### "Cannot reach localhost:9090"
- Frontend server may not have started
- Check if port 9090 is in use
- Check terminal for errors

### "Cannot login"
- Verify credentials: admin@demo.com / DemoAdmin123!
- Check database connection
- Review server logs

### "LLM not found" error
- Go to Settings → AI Context
- Configure LLM first (requires API key)
- Save settings before testing

### "Training failed"
- Verify database DDL syntax is valid
- Check backend logs for details
- Try simpler DDL first (one table)

### "Chat doesn't appear"
- Refresh browser page
- Check browser console (F12) for errors
- Verify backend is running on port 3000
