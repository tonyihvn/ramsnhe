                          APPLICATION STARTUP FLOW
═══════════════════════════════════════════════════════════════════════════════

npm start / npm run dev
    ↓
Express initializes
    ↓
Database connection established
    ↓
Vanna server manager initializes
    ↓
Python app starts on localhost:8888
    ↓
Manager waits for server readiness (2 second timeout)
    ↓
Database credentials auto-passed via env vars
    ↓
Express server listens on configured port
    ↓
Frontend available at http://localhost:3000 (or configured)
    ↓
Vanna accessible at http://localhost:8888 (internal)
    ↓
App ready for use! ✅

SHUTDOWN SEQUENCE:
Express receives SIGTERM/SIGINT
    ↓
Vanna manager initiates graceful shutdown
    ↓
Sends SIGTERM to Python process
    ↓
Waits 3 seconds
    ↓
Force kills if needed (SIGKILL)
    ↓
Express closes
    ↓
Process exits

                          CONFIGURATION OPTIONS

Environment Variables (.env file):

VANNA_PORT=8888
  Default port for Vanna server
  Can be changed if port conflicts

VANNA_HOST=0.0.0.0
  Host interface to bind to
  0.0.0.0 = all interfaces

VANNA_AUTO_START=true
  Auto-start on app launch
  Set to 'false' to disable

DB_HOST=localhost
  Database hostname (passed to Vanna)

DB_PORT=5432
  Database port (passed to Vanna)

DB_NAME=ramsnhe
  Database name (passed to Vanna)

DB_USER=postgres
  Database username (passed to Vanna)

DB_PASSWORD=...
  Database password (passed to Vanna)

DATABASE_TYPE=postgres
  Database type for Vanna

                            TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Vanna Server Won't Start
──────────────────────────────
Symptoms: Status shows "✗ Error" or stays "○ Stopped"

Solutions:
  1. Check Python installed: python3 --version
  2. Install Vanna: pip install vanna flask flask-cors
  3. Check port 8888: netstat -ano | findstr :8888
  4. Check Express logs for [Vanna Server] errors
  5. Try manual start: python3 vanna_server/app.py

ISSUE: Ollama Models Won't Load
──────────────────────────────
Symptoms: "Detect Models" shows "Ollama not running"

Solutions:
  1. Start Ollama: ollama serve
  2. Pull a model: ollama pull llama2
  3. Check URL: http://127.0.0.1:11434/api/tags
  4. Test: curl http://127.0.0.1:11434/api/tags

ISSUE: UI Doesn't Show New Tabs
──────────────────────────────
Solutions:
  1. Hard refresh browser: Ctrl+Shift+R
  2. Clear cache: Ctrl+Shift+Delete
  3. Restart dev server
